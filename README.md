# Smoke City

A Django-based web application built for managing services, media, and shop functionality.  
This project includes custom apps, admin customization, and a clean UI structure.

## Features
- Django admin customization
- Core app for global configuration
- Shop app for services and listings
- Media handling for uploaded files
- Responsive templates and static assets

## Tech Stack
- Python / Django
- HTML, CSS, JavaScript
- SQLite (development)
- Git & GitHub for version control
